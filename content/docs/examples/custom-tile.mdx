Pass a raster tile URL template to `rasterUrl` to load tiles from a different provider or your own tile server. Use `darkRasterUrl` to provide different tiles for dark mode.

## Vector Tiles

Pass a [MapLibre style](https://maplibre.org/maplibre-style-spec/) URL to `vectorStyleUrl` to render vector tiles. Vector tiles require WebGL, so you can also pass a `rasterUrl` to use as a fallback on devices without WebGL support.
